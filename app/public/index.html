🎧 Mofibo (Storytel)

Henter de bøger, du har færdiglæst/lyttet på Mofibo, ind i biblioteket som »læst, men ikke ejet«. Synkroniseringen kører automatisk én gang i døgnet — du kan altid hente med det samme herunder. Din e-mail og dit kodeord gemmes krypteret på din egen server og sendes aldrig til browseren igen.
Hvad skal hentes?

🔍 Berig med ISBN og covers

Slår bøger uden ISBN op på titel + forfatter (bibliotek.dk) og udfylder ISBN, cover og serie — kun tomme felter, og kun når titel og forfatter matcher. Kan stoppes og genoptages når som helst.

💾 Sikkerhedskopi

Gem en kopi af hele dit bibliotek som en fil, eller hent en tidligere kopi ind.

ℹ️ Om appen

Min Bogreol kører på din egen server (Yggdrasil Panel) og gemmer alt i sin egen database dér. Log ind fra alle dine enheder – biblioteket er altid det samme. Bogopslag sker via Google Books og Open Library. Læg appen på hjemmeskærmen: åbn browserens menu og vælg »Føj til hjemmeskærm«.
